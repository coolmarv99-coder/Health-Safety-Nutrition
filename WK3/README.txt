USE
Open index.html in a modern web browser. Keep the images folder beside
index.html so the Week 3 Maya image displays correctly. No internet connection
or external assets are required for the guide itself. The source link in the footer opens
the assigned LibreTexts chapter when internet access is available.

LEARNING PURPOSE
This guide introduces the Safety Detective design family through the recurring
NOTICE → ASSESS → PREVENT → RESPOND reasoning cycle. Five stations address the
cycle, a realistic Safety Scan with unsafe/acceptable/ambiguous conditions,
active-supervision positioning, a complete injury-response case, and the
balance between protection and developmentally appropriate challenge.

The guide preserves the shared CLDV-05 course shell: navigation, five-station
progress, immediate explanatory feedback, retry behavior, shuffled answers,
responsive layout, keyboard-accessible controls, and a full-guide reset.
