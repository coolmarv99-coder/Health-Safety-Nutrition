CLDV-05 — Week 2 Interactive Reading Guide Prototype
The Whole-Child Well-Being Lens

Primary source:
Jennifer Paris, Health, Safety, and Nutrition, Chapter 1:
“Children’s Well-Being and Early Childhood Education”

CONTENTS
- index.html — complete self-contained guide (HTML, CSS, and JavaScript)
- images/CLDV-05 Vignette Image 2(1).png — Week 2 Maya course image
- README.txt — this file

USE
Open index.html in a modern web browser. Keep the images folder beside
index.html so the Week 2 Maya image displays correctly. No internet connection
or external assets are required for the guide itself. The source link in the footer opens
the assigned LibreTexts chapter when internet access is available.

PROTOTYPE PURPOSE
This guide establishes the proposed shared CLDV-05 shell: navigation,
five-station progress, immediate explanatory feedback, retry behavior,
responsive layout, keyboard-accessible controls, and a full-guide reset.

Week 1 remains deferred. No other weekly guides are included in this package.
