DESIGN
- Continues OBSERVE → COMPARE → SUPPORT → ACT.
- Uses the supplied “Germ Detective” vignette without turning health into fear.
- Includes a transmission-chain investigation and nuanced Health Check.
- Applies handwashing, universal precautions, cleaning/sanitation,
  exclusion judgment, objective communication, and environmental health.
- Randomizes conventional answer choices and provides explanatory feedback.
- Preserves the shared CLDV-05 shell, accessibility, responsive behavior,
  progress tracking, and restart function.

USE
Keep the images folder beside index.html. Open index.html in a modern browser.
The guide itself requires no external assets; the assigned-reading link requires
internet access.
